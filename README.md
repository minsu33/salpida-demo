# 살피다 시연용 웹앱

선결제 하기 전에, 업장부터 살펴보세요. 강남대 데이터사이언스 아이디어 경진대회 3조 시연용 모바일 웹(React + Vite, PWA)이다.
업장은 가상 예시이고, 크기 단계와 안내 기준은 서울·경기 인허가 분석 결과를 따른다. 서버와 API 키는 쓰지 않는다.

## 실행
```bash
npm install
npm run dev
```

## 시연 흐름
온보딩 → 지도(보장 업장 필터, 업장 비교) → 업장 상세(결제 전) → 결제 전 체크 → 체크 결과 → 보장 업장 → 이용권 등록 → 알림 배너 → 알림 → 업장 기록

## 배포
Vercel에서 이 레포를 Import → Deploy. 폰 사파리에서 열고 공유 → 홈 화면에 추가하면 앱처럼 열린다.
