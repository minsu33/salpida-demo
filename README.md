# 살피다

선결제 하기 전에, 업장부터 살펴보세요.

강남대 데이터사이언스 아이디어 경진대회 3조의 시연용 모바일 웹입니다.

https://salpida-demo.vercel.app

## 실행

```bash
npm install
npm run dev
```

## 브랜치

- `develop`: 작업용
- `main`: 발표용 (푸시하면 위 주소에 자동 배포)

## 참고

- 업장은 예시이고, 크기 단계와 안내 기준은 서울·경기 인허가 분석 결과를 따릅니다.
- 서버와 API 키는 쓰지 않습니다.
- 주소 뒤에 `?reset`을 붙이면 처음 상태로 돌아갑니다.
